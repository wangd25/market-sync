# Testing

`pnpm test` runs deterministic Vitest suites for fixed/adjusted delay, pause/resume and effective drift, buffering recovery, live-edge seek clamping, rate changes, invalid delay, contradictory anchors, confidence, strict atomic freeze, out-of-order and duplicate ticks, bounded history, dual-outcome delayed reveal, delayed sports-state reveal and interpolation, sparse play-by-play merging, spoiler-blind next-score matching, unique baseball state matching, next-run matching, HLS program-time delay validation, provider schemas, the exact reproduced MLB URL, event-versus-market resolution, multi-contract selection, recorded Polymarket payload normalization, browser-safe fetch receiver behavior, history normalization, WebSocket heartbeat/reconnect/switch cleanup, Kalshi parsing, fixture progression, sports strategies, mock gateway availability, and room separation.

Research-path coverage proves strict schema rejection, session isolation, duplicate suppression, count bounds, viewer-cutoff summaries, separated latency distributions, approximate timestamp handling, drift reporting, and allowlist-only JSONL. Sports orchestration coverage proves authority/capability selection, stale-source failover, out-of-order reporting, bounds, revision replacement, correction visibility at receipt time, and rejection of unmarked score rollback. Adapter tests assert normalized sports provenance and ensure provider-only fields do not cross the boundary.

Production-evaluation coverage additionally proves bounded JSONL import, per-signal timestamp separation, missing/correction/ordering calculations, canonical event resolution, source hysteresis, capability-specific selection, period/clock regression rejection, score disagreement, gateway replay, sync-mode persistence, confirmed program-time candidate planning, undo restoration inputs, and persistent wheel zoom with explicit reset.

`pnpm test:e2e` starts the web app and gateway. It verifies fixture/manual sync controls, pause, strict freeze, chart wheel zoom/reset, persisted sync modes, the exact Polymarket MLB event URL with a sanitized multi-contract response and delayed history, responsive phone use, two-client rooms with separate delays, explicit extension permission denial, and the built Manifest V3 delayed-overlay show/fullscreen/hide path. Run `pnpm build` first so `.output/chrome-mv3` exists. Install Chromium once with `pnpm exec playwright install chromium`.

Live smoke tests are intentionally optional and should skip clearly on network unavailability. No required test depends on a live event or credentials. Provider fixture payloads must be sanitized before they enter source control.

For any provider trial, capture the same completed games across candidates and report score, clock, and play-by-play separately: sample count, median, p95, worst latency, missing-event rate, duplicate rate, correction rate, out-of-order rate, disconnect duration, and timestamp-quality mix. Re-run with forced disconnect/replay and delayed-correction fixtures. A source is not eligible for automatic anchoring until it has stable wall-clock timestamps, deterministic replay/revision semantics, and an acceptable missing-play rate.
