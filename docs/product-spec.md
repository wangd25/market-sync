# Product specification

Phase 2 adds a complete public Polymarket extension session to the deterministic vertical slice. Users can browse bounded live/upcoming sports discovery, search/filter it, paste official event or market references, choose among eligible contracts, bootstrap history, and receive public market/sports WebSocket updates. Demo remains a clearly labeled offline mode.

Every market-derived value is revealed through the viewer-time cutoff. Binary contracts show both projected outcomes, including both live prices, bid/ask state, direction, and chart history. The primary surfaces are the responsive companion app, restrained white liquid-glass Chrome side panel, and minimal delayed overlay. Accessible HTML video events can adjust or freeze the timeline; inaccessible players fall back to manual controls. Clockless sports use unique discrete-state or event calibration. MarketSync is read-only and source-agnostic. It does not access protected video, bypass platform restrictions, place orders, copy provider frontends, or claim provider affiliation.

Phase 2 success is deterministic offline verification plus a working optional public-live path. Production-grade shared rooms, authoritative sports feeds, OCR, analytics, billing, and trading are not part of this product slice.
